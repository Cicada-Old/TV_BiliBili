# 贡献指南

欢迎提交问题反馈与改进建议。为便于定位，请按以下格式提供信息。

## 提 Issue 时请附

- 游戏版本与操作系统；本 mod 版本（当前 1.0.0）。
- 复现步骤：输入了什么链接 / 按了哪些按钮 / 在什么场景下发生。
- 期望行为与实际行为。
- 相关日志片段：`ModData/TV_BiliBili/` 下的纯文本日志，或游戏 `Player.log`。请勿上传存档、账号信息或含个人隐私的截图。
- 是否与 30 个以上 mod 共存；如有，列出可能与日历 UI 冲突的 mod。

## 提交代码前

- 先读 [架构说明](ARCHITECTURE.md) 与 [开发说明](../DEVELOPMENT.md)。
- 不把游戏自带 DLL、构建产物 `bin/`、`obj/`、存档或内部证据提交进仓库。
- 不改变已冻结的 1.0.0 产物指纹；若需变更产品行为，按新版本处理并更新 CHANGELOG / ARCHIVE。
- 构建命令：`dotnet build Source/TV_BiliBili.csproj -c Release`。
- 若修改公开文档，中英文对应文件尽量同步；至少保证中文版完整。

## 范围边界

本 mod 不支持弹幕、本地视频、独立播放器、av / 短链 / 番剧 / 付费 / 充电 / 直播、投影仪前置；相关需求不作为缺陷处理。
