# 功能说明

本文件说明 v1.0.0 的功能点与使用边界。安装步骤见 [安装与使用](安装与使用.md)，兼容与依赖见 [兼容性与依赖](兼容性与依赖.md)。

## 播放器入口

- 店铺日历新增第 4 个标签页「播放器」。
- 点店铺日历显示器仍打开原版日历；播放器没有独立按钮或窗口。

## 输入与解析

- 支持 B 站视频网页全链接（可带查询参数）和纯 BV 号。
- 多分 P / 合集固定取第一个分 P。
- 不支持 av 号、`b23.tv` 短链、番剧 / 付费 / 充电专属、直播、非 B 站网址、4K / 登录态内容。
- 留空输入会提示「请输入 B 站视频网址」；无法识别会提示「无法识别 BV 号」。

## 播放与画面

- 画面在标签页内显示，并四角贴合投到店铺日历显示器。
- 不裁片源黑边；竖屏视频出现黑边是预期行为。
- 控件：播放 / 暂停、进度拖动跳转、时间显示、音量滑块。
- 状态文案：就绪 / 解析中… / 加载中… / 播放中 / 已暂停 / 播放失败 / 无法识别 BV 号 / 请输入 B 站视频网址。
- 失败原因写入日志 `PLAY_FAIL` 明细，界面统一显示「播放失败」。

## 生命周期

- 换标签页、关闭日历：保留网址、进度与播放状态，继续播放。
- 睡觉（日结）、离店：暂停；返回后自动续播。
- 打开 ESC 菜单或选项页：暂停；关闭后延时复查再续播，避免同帧切换爆音。
- 离开存档回主菜单：停止播放并释放资源；重新进入存档可再次播放。

## 本地行为

- 不下载、不缓存视频，不生成播放列表。
- 不写玩家存档；只在自身 ModData 目录写纯文本运行日志供排查。
- 唯一能力声明为 `network`，首次启用需玩家批准。
