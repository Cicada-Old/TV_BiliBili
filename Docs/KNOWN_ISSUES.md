# 已知问题

本文件是 BetterBuild 风格命名入口；完整中文说明另见 [已知问题与限制](已知问题与限制.md)。以下内容与该文件一致。

## 已书面接受的观察项

| 项 | 状态 |
|---|---|
| 日结续播回归 | 游戏内时间门控不可达；用户已书面接受为观察项，不判缺陷 |
| 离店 / 返回店内、手动暂停不被覆盖、暂停恢复时延 | 用户实际游玩验收判定通过，非本轮自动化取证 |
| 播放中 CPU 增量 | 实测 +13.22%，门限 ≤15%，接近但未超限 |
| 10 次换片工作集 | +29.88 MB 且非单调，门限 ≤150 MB，通过；句柄 +127 仅登记 |

## 设计限制

- 仅支持 B 站网页全链接与纯 BV 号；av / 短链 / 番剧 / 付费 / 充电 / 直播 / 非 B 站网址不支持。
- 多分 P 固定取第一个分 P，无分 P 选择。
- 不提供 1080P / DASH 手动切换，不依赖登录态。
- 竖屏黑边为预期行为；不裁片源黑边。
- 1920×1080 为基准，1600×900 已验证，其他分辨率未逐一测试。
- 播放器是日历第 4 标签，无独立窗口；点显示器仍打开原版日历。

## 改进项

`PLAY_FAIL` 前缀二义性、`lastError` 代际归属、源码注释与文案冲突、bootstrap 未打印 DLL 指纹等，均为下次实质变更的改进项，不阻塞 1.0.0。
