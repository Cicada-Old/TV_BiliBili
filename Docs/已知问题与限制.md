## 三、行为限制（设计如此，非缺陷）

- **多分 P / 合集**：固定取第一个分 P，不提供分 P 选择。
- **输入范围**：仅 B 站网页全链接与纯 BV 号；`av` 号 / `b23.tv` 短链 / 番剧 / 付费 / 充电 / 直播 / 非 B 站网址不支持，会提示无法识别或播放失败。
- **清晰度**：取接口提供的合流直链；不提供 1080P / DASH 手动切换、不依赖登录态。
- **竖屏黑边**：不裁片源黑边，竖屏视频出现黑边是预期行为（C-13 明文）。
- **本地不保留视频**：不下载、不缓存、不生成播放列表；仅在自身 ModData 写纯文本运行日志。
- **无独立播放器**：播放器是日历的第 4 个标签页，没有独立按钮或窗口；点显示器仍打开原版日历。
- **非基准分辨率**：布局以 1920×1080 为基准，1600×900 已验证，其他分辨率未逐一测试。
