# 店铺小电视：也许是B站？ — 安装与使用

> mod `<ID>`：`TV_BiliBili` · 发布版本：1.0.0 · 适用游戏：《深空当铺：可能是偷的》1.0.0
> 本页只讲怎么装、怎么用；兼容性 / 依赖见 `兼容性与依赖.md`，已知问题见 `已知问题与限制.md`，版本变更见 `更新说明.md`。

## 一、这是什么

给店铺日历加第 4 个标签页「播放器」。粘贴一个 B 站视频网页链接或 BV 号，画面就能在标签页里播放，同时投到店铺里日历显示器上。点显示器仍然打开原版日历，不影响原本玩法。

## 二、安装

1. 关闭游戏。
2. 把 `TV_BiliBili.dll` 和 `manifest.xml` 两个文件放进游戏根目录的 `Mods/TV_BiliBili/` 文件夹（没有就新建）。
3. 启动游戏，在 Mod 列表里启用本 mod。
4. **首次启用需要在游戏里批准它的 `network`（联网）能力**——这是游戏对 mod 的安全授权，属正常流程；不批准则无法取视频流。

发布包只需要这两个文件，不需要 `.dll` 以外的其他库：游戏自带的 Unity、Newtonsoft.Json、Harmony 等由游戏运行时提供，不要额外复制。

## 三、使用

1. 在游戏里点店铺日历，打开日历界面。
2. 切到最右边的第 4 个标签页「播放器」。
3. 在输入框里粘贴以下任意一种：
   - B 站视频网页全链接（例如 `https://www.bilibili.com/video/BV1GJ411x7h7?spm_id_from=...`，可带查询参数）；
   - 纯 BV 号（例如 `BV1GJ411x7h7`）。
4. 点播放按钮开始播放。

### 支持与不支持的输入

| 支持 | 不支持（会提示「无法识别 BV 号」或「播放失败」） |
|---|---|
| B 站网页全链接、纯 BV 号 | `av` 号、`b23.tv` 短链、番剧 / 付费 / 充电专属、直播、非 B 站网址、4K / 登录态内容 |

- 留空输入再点按钮会提示「请输入 B 站视频网址」，不会发网络请求。
- 多分 P / 合集视频固定取第一个分 P。
- 接口返回的网址若不是可播放的 http(s) 直链会被拒绝，不会尝试打开。

### 画面与控制

- 画面：标签页内显示，同时四角贴合投到店铺日历显示器；不裁片源黑边（竖屏视频出现黑边是正常现象）。
- 控件：播放 / 暂停、进度条拖动跳转、时间显示、音量滑块。
- 状态文案（8 种）：就绪 / 解析中… / 加载中… / 播放中 / 已暂停 / 播放失败 / 无法识别 BV 号 / 请输入 B 站视频网址。失败原因另写进日志的 `PLAY_FAIL` 明细，界面统一显示「播放失败」。

### 播放时打开菜单

- 打开 ESC 菜单或选项页时，视频会暂停，关掉后接着播；这段时间不会出声。
- 换标签页、关掉日历再打开：视频继续播，网址和进度保留。
- 睡觉（日结）、离店：暂停，回来自动续播。
- 离开存档回主菜单：停止播放并释放资源；重新进入存档后可再次播放。

## 四、本地不保留视频

本 mod 只联网读取视频流，不会把视频下载或缓存到本地，也不写玩家存档或 ModData 视频文件。运行时会在 mod 自己的 ModData 目录写一份**纯文本运行日志**供排查，不含视频内容。

## 五、卸载

关闭游戏，删掉 `Mods/TV_BiliBili/` 里的这两个文件即可。重新进入游戏后日历恢复原版三标签布局，存档不受影响。
