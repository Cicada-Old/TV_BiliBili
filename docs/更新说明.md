# 店铺小电视：也许是B站？ — 更新说明

> mod `<ID>`：`TV_BiliBili` · 发布版本：1.0.0 · 整理：发布流程 D 前半段（实现工程师），2026-11-17

## v1.0.0（首次发布）

发布版本 **1.0.0**；兼容游戏版本 **1.0.0**（覆盖 1.0.0 全部修订版）。本次为首次发布，无上一公开版本可比，故从「从零到已验收交付态」整体说明。

### 新增功能

- 店铺日历新增第 4 个标签页「播放器」；点显示器仍走原版日历。
- 支持粘贴 B 站视频网页全链接或纯 BV 号起播：接口取 cid → 取合流直链 → 播放；多分 P 取第一个分 P。
- 画面在标签页内显示，并四角贴合外投到店铺日历显示器；不裁片源黑边。
- 控件：播放 / 暂停、进度拖动跳转、时间显示、音量滑块。
- 生命周期：换标签 / 关日历保留续播；睡觉 / 离店暂停、返回续播；离开存档停止并释放资源、重进可再播。
- ESC / 选项菜单期间暂停、关闭后续播，带延迟复查防爆音。
- 失败状态统一为「播放失败」，原因写入日志 `PLAY_FAIL` 明细。
- 仅声明 `network` 能力；本地不保留视频、不写玩家存档。

### 已知限制

详见 `已知问题与限制.md`。要点：仅支持 B 站网页链接 / BV 号，不支持 av / 短链 / 番剧 / 付费 / 充电 / 直播；非基准分辨率未逐一验证；竖屏黑边为预期；日结续播按用户书面接受的观察项处理。

### 依赖与兼容

详见 `兼容性与依赖.md`。mod 文件夹里的运行必需文件仅 `TV_BiliBili.dll` + `manifest.xml` 两个；Release 压缩包另附 4 份用户文档，文档不参与加载。12 个运行时引用由游戏提供，无 NuGet，首次启用须在游戏内批准 `network` 能力。
